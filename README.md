## ⚡ Project overview

**MiroFish** It is a new generation AI prediction engine based on multi-agent technology. By extracting real-world seed information (such as breaking news, policy drafts, financial signals), a high-fidelity parallel digital world is automatically constructed. In this space, thousands of intelligent agents with independent personalities, long-term memories and behavioral logic interact freely and evolve socially. You can dynamically inject variables through "God's perspective" to accurately deduce future trends.——**Let the future be previewed in the digital sandbox to help decision-makers win after hundreds of simulated battles.**。

> You only need to: Upload the seed material (data analysis report or interesting novel story), and describe the predicted needs in natural language</br>
> MiroFish Will return: a detailed forecast report, and a deeply interactive, high-fidelity digital world

### our vision

MiroFish is committed to creating group intelligence mirrors that map reality, breaking through the limitations of traditional predictions by capturing the emergence of groups caused by individual interactions.：

- **Yu Macro**：We are a rehearsal laboratory for policymakers, allowing policy and public relations to trial and error with zero risk.
- **Yu Weiwei**：We are a creative sandbox for individual users. Whether it is deducing the ending of a novel or exploring imagination, it can be interesting, fun and within reach.

From serious predictions to fun simulations, we allow every if to see the result, making it possible to predict everything.。

## 🔄 Workflow

1. **Map construction**：Realistic seed extraction & Individual and group memory injection & GraphRAGbuild
2. **Environment setup**：Entity relationship extraction & Character generation & Environment configuration Agent injection simulation parameters
3. **Start simulation**：Dual platform parallel simulation & Automatically analyze and forecast demand & Dynamically update timing memory
4. **Report generation**：ReportAgentRich toolset for in-depth interaction with the post-simulation environment
5. **Deep interaction**：Have a conversation with anyone in the simulation world & Conversation with ReportAgent

## 🚀 quick start

### 1. Source code deployment (recommended）

#### Prerequisites

| tool | Version requirements | illustrate | Installation check |
|------|---------|------|---------|
| **Node.js** | 18+ | Front-end operating environment, including npm | `node -v` |
| **Python** | ≥3.11, ≤3.12 | Backend operating environment | `python --version` |
| **uv** | Latest version | Python Package manager | `uv --version` |

#### 1. Configure environment variables

```bash
# Copy the sample configuration file
cp .env.example .env

# edit .env file, filling in the necessary API keys
```

**Required environment variables：**

```env
# LLM APIConfiguration (supports any OpenAI SDK format LLM API）
# It is recommended to use Alibaba Bailian platformqwen-plusModel：https://bailian.console.aliyun.com/
# Note that it consumes a lot of money. You can try a simulation with less than 40 rounds first.
LLM_API_KEY=your_api_key
LLM_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
LLM_MODEL_NAME=qwen-plus

# Zep Cloud Configuration
# Free monthly quota can support simple use：https://app.getzep.com/
ZEP_API_KEY=your_zep_api_key
```

#### 2. Install dependencies

```bash
# Install all dependencies in one click (root directory + front end + rear end）
npm run setup:all
```

Or install it step by step：

```bash
# Install Node dependencies (root directory + front end）
npm run setup

# Install Python dependencies (backend, automatically create virtual environment）
npm run setup:backend
```

#### 3. Start service

```bash
# Start the front and back ends at the same time (execute in the project root directory）
npm run dev
```

**Service address：**
- front end：`http://localhost:3000`
- rear end API：`http://localhost:5001`

**Start alone：**

```bash
npm run backend   # Start backend only
npm run frontend  # Start frontend only
```

### 2. Docker deployment

```bash
# 1. Configure environment variables (same source code deployment）
cp .env.example .env

# 2. Pull the image and start it
docker compose up -d
```

By default, the file in the root directory will be read. `.env`，and map the port `3000（front end）/5001（rear end）`

> exist `docker-compose.yml` The acceleration mirror address has been provided through comments and can be replaced as needed.
